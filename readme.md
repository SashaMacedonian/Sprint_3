# Проект автоматизации тестирования бургерной
1. Основа для написания автотестов — фреймворк selenium + pytest
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v.
4. Файл с тестами test_stellar_burgers.py
5. Файл с локаторами locators.py
6. Файл с фиктсруами conftest.py
7. Файл с дополнительными функциями helpers.py
